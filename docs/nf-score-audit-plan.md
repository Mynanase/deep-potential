# 外围稀疏区域 NF 一阶梯度可靠性与负密度来源

所有代码、配置、运行和验收遵守执行项目的 [AGENTS.md](/Users/qttao/Documents/Research/dpjax-phase2/AGENTS.md)。

**目标**：判断外围区域的一阶 log score 是否有偏、这些偏差是否影响力反演，以及是否对 Φ-NN 的负密度和高频变化有因果贡献。最终结论按“空间区域 × 速度覆盖 × 物理尺度 × 产品（score／力／密度）”给出。

**首轮范围**：冻结来源 → 数值检查与解析校准 → 留出样本弱检验及局部力 → 最小 Plummer P00/P11 → 证据裁决。先完成这条链，再决定是否增加混合臂、数据量或模型变体。

**执行边界**：阅读本文不构成自动执行所有阶段的授权。以用户本次任务中明确的步骤、可修改范围和算力预算为准；若用户已授权连续阶段，则通过相应关口后自主推进，不重复索取相同授权。未授权训练时，完成代码、测试、输入和成本方案后交付。

### 4.2 点集、权重与共享缓存

先固定三类诊断集，另为 T4 冻结配对训练池：

1. `heldout`：真实粒子、质量权重、原始身份/行号、探索或确认资格。
2. `velocity_probes`：固定位置与共享速度、proposal 来源、目标测度及重要性权重。NF 抽样点标明模型外推风险。
3. `spatial_grid`：独立空间网格，用于力、密度、壳质量与谱；明确体积/面积/径向权重。
4. `paired_constraints`（T4）：共同 Φ 训练/验证划分、顺序和权重；不混用最终评估网格。

默认分层候选为 q 边界 `[0.1,0.2,1,2,3,4.5,6,7]`（7 个区间），另报 2–10、10–30、30–50、50–70 kpc；1–2 kpc 由前者保留。外区再按预先指定的 6D 距离度量/稀疏度、速度分位、角向覆盖分层。无可信逃逸势时只报速度层，不伪造逃逸余量真值。

### T1 / Agent A：数值链与共享 score 缓存

**输入**：T0 manifest、点集、冻结模型、允许的求导预算。

**动作**：

1. 适配现有审计的路径/模型/区域输入；不搬用旧 checkpoint 编号或历史通过阈值。
2. 同点重算保存的 `dlnf_deta`；核对 `log n(q)+log P(p|q)` 的完整梯度、位置相关变换与 Jacobian 项。若是密度混合，检查混合 score 的后验密度权重；单 flow 无需额外展开 ensemble 研究。
3. 内中外分层比较 autodiff 和多个差分步长，要求存在相邻步长的稳定区间；不能只挑最小误差的一步。CNF 做 ODE 容差和精度敏感性；随机 trace 固定探针并另查方差。

### T2 / Agent B：校准并执行 Stein 弱 score 检验

**输入**：T0 目标尺度与总体；解析 mock；实际 NF 检验使用 T1 合格缓存。

**动作**：

1. 先用小型固定测试函数库：`h=e_j ψ(z)`，覆盖六分量、外区平滑窗和少量预定波长。冻结函数、幅度归一化和权重方式；窗口导数进入散度。
2. 在 score 正确的 mock 上检验零假设与区间覆盖；采用独立重复样本，报告假阳性率的不确定度。
3. 注入 `δlogF=εψ_k` 对应的 score 扰动，覆盖目标幅度/波长和外区样本量，报告功效及 Monte Carlo 误差。任意非梯度向量扰动另标压力测试。
4. 以联合区间/联合统计量处理多函数，不把大量局部 2σ 当发现。对质量权重、局部窗口覆盖、相关性假设和边界作校准；报告局部支持度，而不只报全局 ESS。
5. 校准合格后，在真实留出集估计效应与区间。需要自适应选窗时只用探索集，独立确认集留到函数和分析规则冻结后使用。

**测试/交付**：边界项、窗口散度、质量权重和注入效应的解析测试；`weak_score_tests` 数组/指标，包含投影定义、区间、多重校准、检出率和证据资格。

**停止/放行**：校准失真先修检验。未知选择边界、无合格确认集或目标尺度功效不足时记 uncertain/探索性；不显著不自动通过。有限投影通过不等于逐点 score 正确。

### T3 / Agent C：Plummer oracle 与局部力反演

**输入**：T0 mock 定义与共享速度点；T1 数值合格的 NF score 可后接入。

科学结果分三类，分别对 score、力、密度报告：

## 附录 A. 必要公式与科学边界

### A1. 单位、score 与密度

[
q=x/L,\quad p=v/V,\quad \phi=\Phi/V^2,\quad
\alpha=aL/V^2=-\nabla_q\phi,\quad
s_q=\nabla_q\log F,\quad s_p=\nabla_p\log F.
\]

[
R(s,\alpha)=p\cdot s_q+\alpha\cdot s_p,\qquad
\rho=\frac{V^2}{4\pi GL^2}\nabla_q^2\phi
=-\frac{V^2}{4\pi GL^2}\nabla_q\cdot\alpha.
\]

`dlnf_deta` 是一阶 log 梯度。普通 DF 梯度的平方残差带有额外 `F²` 权重，不能只改数组名而保持原解释。若 `F=n(q)P(p|q)`，位置 score 包含 `∇q log P` 与所有位置相关变换项。

光滑输入下有限 affine+tanh 网络是 C∞；它不保证导数准确或密度为正。负密度惩罚只抑制负 Laplacian，不能认证平滑性。密度为总引力源密度，不是恒星直方图；轴剖面也不是球壳平均。

### A2. Plummer oracle

取 `a=5 kpc` 为候选尺度，实际 mock 参数在 T0 冻结；令 `b=a/L`、`μ=GM/(LV²)`，

[
\phi(q)=-\frac{\mu}{\sqrt{|q|^2+b^2}},\quad
\epsilon=-\left[\frac{|p|^2}{2}+\phi(q)\right]>0,
\]

[
s_q^*=-\frac{7}{2\epsilon}\nabla_q\phi,\qquad
s_p^*=-\frac{7}{2\epsilon}p.
\]

逃逸边界 `ε→0` 的 score 发散，应单独分层；不静默裁剪真值。报告分量/向量误差的中位数、p84、p95/p99、RMS 和尾部贡献。相对误差需要预先定义尺度下限。

选择后的 `F_sel∝SF` 在内部满足 `s_sel=s+∇log S`；硬边界需要单独处理。截断、外区重采样及 clean/smooth 规则都不能未经检查当作原始 DF。

### A3. Stein 弱检验

对真实样本总体 F、`z=(q,p)`，选光滑向量函数 h，使 `Fh` 的边界通量消失：

[
T_h=\mathbb E_F[\hat s\cdot h+\nabla_z\cdot h]
=\mathbb E_F[(\hat s-s_*)\cdot h].
\]

它不需要真 score 或稳态假设，但只检验有限投影。质量加权经验估计为

[
\widehat T_h=\frac{\sum_i w_i\,[\hat s(z_i)\cdot h(z_i)+\nabla_z\cdot h(z_i)]}{\sum_i w_i}.
\]

若用窗局部化，将窗放入 h 并求导；只按壳筛选后套无边界公式不成立。若另作局部归一化，明确其分母并在区间/功效计算中一并处理。六维坐标度量与 h 幅度归一化必须固定，否则不同窗的效应量不可直接比较。

正确能量依赖的多种平衡 DF 可共享同一真势，所以小 CBE 残差不保证完整 score 准确。Stein 未检出也不控制未覆盖区域或未测试方向的误差。

### A4. 局部力、偏差与投影

固定 q、同一组 p 和非负权重 W，设 `C_i=ŝp,iᵀ`、`y_i=−p_i·ŝq,i`，

[
\hat\alpha=\arg\min_\alpha\|W^{1/2}(C\alpha-y)\|^2.
\]

稳态 mock 中令 `E=Cα*−y=p·Δsq+α*·Δsp`。若加权矩阵满列秩，

[
\delta\alpha=-(C^TWC)^{-1}C^TWE.
\]

实施使用 QR/SVD，不直接求逆。令 `D=W^{1/2}C`、`e=W^{1/2}E`，`D D^+e` 是可被力变化吸收的部分，`(I−D D^+)e` 是不可消除部分。`mean(E)` 不能替代相关投影。

该恒等式只针对固定点、固定权重、无正则的平方目标。稳健损失、裁剪和正则改变估计方程，必须另作分析。重要性权重来自目标/proposal 比值，`exp(logF)` 不是通用权重。

### A5. 有完整独立真力时的弱动力学分解

仅有包围质量曲线不足以提供非球对称系统的三维真加速度。若另有可信 `α*(q)`，设 `b(z)=(p,α*(q))`、`h(z)=ψ(z)b(z)`、`Lψ=p·∇qψ+α*·∇pψ`，则 `∇z·b=0`，

[
\mathbb E_F[\psi R(\hat s,\alpha_*)]
=T_{\psi b}-\mathbb E_F[L\psi].
\]

在相同边界条件下，右边分为 score 误差矩和真实 CBE 残差矩。只有真力误差已传播、选择/源项和动力学条件经过核验，才将后者解释为稳态偏离；它不恢复逐点真 score 或完整时间导数场。

### A6. 尺度与谱

[
\delta\rho_k=-\frac{V^2}{4\pi GL^2}|k_q|^2\delta\phi_k
=-\frac{V^2}{4\pi GL^2}i k_q\cdot\delta\alpha_k.
\]

势到密度的求导关系明确，score 到力再到密度还取决于可辨识性、目标测度和优化，必须用同点替换测量。固定条件速度或明确的速度路径，避免把随机速度变化误当空间高频；速度分位路径本身随位置变化时，也须说明其含义。

有限窗泄漏、网格分辨率和真值离散噪声分别检查。固定尺度球通量/壳质量可作为更稳健产品，但应明确损失了哪些空间分辨率。不能把跨种子一致或平滑后更好看当作物理认证。
