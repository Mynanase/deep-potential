先保留三项区别：

1. `P(支撑外 | 负值)=100%` 不代表 `P(负值 | 支撑外)=100%`。报告中的“剩余负值全部在支撑外”和“支撑外全为负”需用不同分母核实。

3. “约束结构/短尺度自由度”是当前优先假设。DF score 误差、局部动力学约束不足、优化和非平衡仍未排除，不能写成“已确认网络过大”。

## R08｜给内区增加一个经过校准的波纹指标（零训练）

**只回答：指标能否区分陡峭背景与目标尺度起伏？**

1. 原 A/Q 表原样保留，标注内区限制。把过渡区和受支持外围作为原指标的主要决策区。
2. 在实际坐标上构造两类合成场：无波纹的平滑陡峭剖面；同一剖面加已知振幅、波长的正弦扰动。径向背景至少用两种斜率，扰动用 2/4/8 kpc 和历史所称约 7 kpc；这些都是测量校准场，不是 Halo 真值。
3. 尝试一个简单的带通诊断，如 `D_ell=G_(ell/2)(rho)-G_ell(rho)`。明确 G 的 ell 是物理 sigma 还是 FWHM，沿用旧定义换算，不能只给“几个格子”。
4. 在与真实数据相同的 mask、卷积边界处理、有效区域上测试。不要把 mask 外填 0 后直接卷积；对不能可靠处理的边缘给出无效标记。尺度间比较使用共同有效区域，并报告剩余面积。
5. 记录平滑背景本身产生的带通响应，以及已知波纹经过过滤后的振幅响应。带通也会响应背景曲率，不能自动消除本次内区问题。
6. 校准通过后，才对全部模型计算相同指标，并保留原像素剖面。校准失败则暂不排名内区，使用过渡区/外围和定点曲线继续后续步骤，不另调滤波参数直到喜欢某个模型。

**输出：** 校准图、滤波定义/有效 mask/响应表、`r08_metrics.json`。原指标与新增指标并列，不能覆盖旧结果。

**判断：** 原 A 几乎不变但校准后的波纹指标改变，说明原指标被背景淹没。两者不一致时保留两者，不选择性报告。

**波长附加检查：** 仅在波纹能跨越多个周期的固定局部区域，使用统一去趋势、窗函数和位置的剖面/自相关比较。区域太窄或 mask 太破碎时不报精确峰值波长。原“约 7 kpc”仍是待复核线索。

## R09｜先算已有三格的效果，再决定缺失第四格是否值得训练（零训练）

**只回答：现有结果已告诉了我们多少？**

按用户报告建立以下候选表，必须经 R07 验证，N0 不根据版本名猜测：

| 格子 | lambda_mass | uniform 点数 | 候选旧模型 |
|---|---:|---:|---|
| C00 | 2000 | N0：读取实际配置 | v5 |
| C10 | 250 | N0 | v6-lam250 |
| C01 | 2000 | 32768 | 缺失 |
| C11 | 250 | 32768 | v7-a2，需确认其余字段一致 |

这里 00→10 表示**降低** lambda，不要沿用“增强权重”的叙述。若 v7-a2 同时改变其他字段，撤销 C11 标记，仅作额外历史结果。

1. 在相同点上统一评估 C00、C10、C11，不用各 run 自己的图尺度或自己计算的 rho_ref。
2. 计算每区每尺度的 `C10-C00`：高 lambda → 低 lambda 的变化；计算 `C11-C10`：低 lambda 条件下增加探针的变化。
3. 同时报告负率、负幅度、A/Q、校准后的内区指标、背景 B、CBE RMS/P99、加速度，以及耗时/实际步数。增点若伴随更新数变化，不能称为纯点数对照。
4. 尚无 C01 时，不计算完整交互作用 `C11-C10-C01+C00`，不填补缺失结果。
5. 若比较波纹位置，使用同一滤波定义的场差图和相关系数；相关很低但振幅相同表示模式变化，不表示消失。相关很高也不能确认是物理结构。

**输出：** `r09_three_cell_metrics.csv`、共同色标差图、每条对照的可比性标签。

**分支：**

- 若 C11 相对 C10 已明显改善关键区指标且动力学代价可接受：下一笔预算优先验证其可复现性；C01 是研究交互的后续选项。
- 若 C11 与 C10 的差异低于预登记筛选线：不继续盲目加点。优先 R10 及 Phi seed 分支。
- 只有“高 lambda 下增加探针是否产生不同效果”会改变下一步选择时，才补 C01；不能为了表格完整而训练。
- 历史源码不完整时，上述结论统一标为历史筛选，不因凑齐四格而升级。

**额外限制：** 每步重采样的 uniform 探针没有固定晶格间距。`(体积/N)^(1/3)` 只是单批典型尺度；需同时记录累计更新次数、ramp 与采样域，不能以一个比值证明约 7 kpc 波纹与探针无关。

## R10｜检查剩余波纹是否仍被目标函数看见（零训练，少量求导）

**只回答：当前负密度项还在哪里起作用，波纹与优化过程是否同步？**

优先用 v6-lam250 和 R09 选出的一个对照，分两小步执行。

**R10a：固定点评估。**

1. 在固定空间点上分别记录负值比例和负惩罚平均值，分支撑内、支撑外且探针域内、探针域外。
2. 分别评估真实数据位置和独立均匀点，不能把 tracer 权重统计与空间体积统计合并。
3. 在固定六维点上计算当前配置对应的训练分项、CBE RMS 与 P99；只用均匀空间点计算质量项，不给它们拼接任意速度。
4. 若存在早/中/晚 checkpoint，固定点复用它们，记录真实更新数、ramp 权重及波纹/负值/背景轨迹；缺失历史 checkpoint 就记录缺失，不为补曲线立即重训。

**R10b：分项参数梯度，仅在 R10a 后仍有必要时。**

1. 先用一批可承受规模的真实六维数据和空间探针验证结果有限、显存可用，然后最多做 8 批。冻结种子和空间域，明确是否因显存使用了子样本。
2. 按实际训练公式分别求 CBE、数据负惩罚、均匀点负惩罚、L2 对 Phi 参数的梯度。记录原始分项及乘 lambda、w(t)、L2 系数后的范数。
3. 记录加权分项梯度的余弦，近零梯度记 NA；说明这是优化器裁剪/预条件之前的梯度，不等于实际参数更新。
4. 子样本得出的只是梯度诊断估计，不要求逐位重现原训练 batch 的更新。

当前惩罚为 `asinh(beta*max(-laplacian(Phi),0))`。对严格正密度点，该项的局部导数为零；因此，即使将 lambda 或探针数量增加，正值波峰也没有直接的平滑惩罚。负点仍可能通过共享参数间接影响正区。这是实现性质，不是剩余波纹成因已被证明。

**输出：** `r10_active_penalty.json`，可用时加 checkpoint 轨迹表、分项梯度表。

**判断：**

- 支撑内质量项不活跃、波纹仍大：降低“继续增大非负惩罚即可解决”的优先级。
- 加权质量梯度显著且与 CBE 常相反，伴随 CBE/加速度恶化：优先检查约束折衷；余弦本身不是物理错误的证据。
- 晚期 CBE 改善趋缓而波纹/背景继续漂移：后续考虑优化时长或正则实验；不要事后只挑最好看的 epoch。
- 质量项仍主要在探针域内的外推区活跃：后续可研究空间权重分配，先固定总混合权重，避免与新增采样数量混杂。

**R07–R10 到这里停下交付一次报告。默认新训练预算为 0。** 若缺少原始产物，交付缺项清单和已完成的独立盘点，不伪造完成状态。

## R12｜先换一个 Phi seed（新增 1 次；需要时再加第 3 个）

**优先情形：** 非负性已满足，剩余波纹的振幅/位置对已有权重与点数变化不敏感。

1. 基于 R11 的参照，只改 `phi.seed`，保持其余所有配置、数据和训练预算一致。从头训练时这是 Phi 整体训练随机性实验，包含初始化、shuffle 和探针变化。
2. 比较密度、加速度、背景、CBE 和波纹图，而不是只看最终总 loss。计算固定点上的模型差、起伏场相关及各区振幅。
3. 若两次差异与欲解释的设置差异同量级，说明一个 seed 不足以给设置排名；下一次预算先用于第 3 个 seed，不同时改宽度或 loss。
4. 若 seed 变化主要移动波峰、加速度/CBE 相近，支持当前训练对这些细节不稳定；尚不能把随机性全部归于初始化。
5. 若同一模式稳定重复，上游 score、共同约束、边界、物理结构或架构偏置仍都有可能；转 R14，不能直接宣布是真实结构。

**输出：** 两个或三个单模型指标并列、差图、描述性离散范围。平均密度图只作附图，不能作为单模型精度提升证据。

## R13｜条件性补 C01 或复验设置效果（不默认运行）

**优先情形：** R09 显示权重/采样效果足以改变实验选择，且可比性允许继续做控制实验。

1. 若 R07 的三格已具可核实的同代码/同起点条件，只补 `lambda_mass=2000, mass_uniform_points=32768`，其他项保持配对条件。
2. 若历史条件不完整，不将一个新 C01 和三个旧模型混为严格四格。先使用 R11 新参照，新增一个最有信息量的单因子对照；只有确有研究价值时再顺序补齐新系列剩余两格。
3. 数量实验中固定 `mass_uniform_weight`、起始权重、ramp、域和每个 CBE batch。uniform 点数不同不改变两个均值的混合系数；也不要求不同形状 PRNG 输出形成嵌套点集。
4. 记录每步点数、累计点数、实际训练步数和墙钟时间。科学对照优先相同更新数；相同墙钟预算回答的是计算效率问题，应单独标注。
5. 四格完整后才计算交互量，并逐项展示。需要确认效果时，给关键两个设置增加相同第二 seed；一个 seed 的四格仍不能作显著性论证。

**输出：** 按新/旧系列明确分组的对照表，以及“继续调权/采样”或“转向 score/表示”的决策。没有必要一轮训练四个新模型。

## R14｜做 Plummer score 来源对照（两次配对 Phi 训练，分开执行）

**优先情形：** 同代码训练可重复，继续改变非负约束收益很小，或怀疑 DF score 的细节被势网络继承。

1. 先验证 Plummer 数据、势尺度、单位、Normalizer 与现有 `plummer_analytic` 实现一致；不能把 Halo12 数据上的 score 直接替换成 Plummer 解析式。
2. 在匹配的固定 Plummer 空间/六维点上，先做零训练检查：解析势给出正确解析密度；解析 score 加解析势的 CBE 接近已确定数值容差；flow score 的位置和速度两部分分别与解析值比较。
3. 用一个固定的已训练 Plummer DF 和同一数据 support，运行 P-flow；再只切换 `score.source` 运行 P-oracle。Phi 初始化、数据顺序、空间探针、损失、训练预算相同。若没有可用 Plummer DF，单列 DF 训练成本，不能隐藏在“两次 Phi”预算中。
4. Plummer 使用自身长度/密度尺度，不照搬 Halo 的 2/4/8 kpc、output_scale 和数值 loss 权重。配对内部保持完全一致，并记录选择依据。
5. 用解析真值比较密度误差、加速度误差、起伏和 CBE；二者都用同一个解析 score 计算一份参考 CBE，另报各自训练 score 下的 CBE。不能用定义不同的 residual 表排名。
6. 如需严格 held-out 行，须在 DF、Normalizer 和 Phi 训练前预留；使用已有 DF 时，对新空间点的检验仍不等于未见观测验证。

**判断：**

- P-oracle 明显好、P-flow 差，且 flow score 误差具有对应结构：支持这套受控模型里上游 score 是重要误差来源；不能直接证明 Halo 起伏同因。
- 两者密度都差，但解析输入检查通过：优先查 Phi 优化、表示和密度可识别尺度。oracle 不自动保证任意密度分辨率。
- 两者都好：说明当前流程能解决这一受控例子，不能据此排除 Halo 的 DF 误差、几何覆盖或非平衡。

**输出：** 两个 Phi run 的真值误差表、score 分量误差表和配对配置 diff。

## R15｜只选择一个后续分支

| 已有证据 | 下一项小实验 | 控制与限制 |
|---|---|---|
| oracle 下仍有明显波纹且优化稳定 | 同深度、宽度减半的单个 Phi 对照 | output_scale、激活和预算先固定；参数量、L2 的实际数值/梯度也记录。不同宽度初始函数不相同，不能声称只改变参数个数 |
| 早期较好、晚期波纹增长 | 一对固定预算/预登记选点规则的训练轨迹比较 | 不事后挑 checkpoint；学习率与 ramp 随总步数变化要明确 |
| flow score 在受控实验中主导 | 固定数据和 Phi 设置，只更换一个 DF seed/checkpoint | 同定义 score 诊断优先，NLL 改善不能替代 score 改善；重新训练 DF 是独立预算 |
| 外围真实信息不足 | 保持 Phi 设置，比较同选择函数下的不同独立 tracer 样本量 | 增加空间非负探针不等于增加观测信息；重复相同粒子也不算新增数据 |
| 多种模型同位置起伏，且局部 CBE 异常 | 局部动力学约束/非平衡检查 | 可先检查 velocity-score 方向覆盖，不先换网络 |

局部约束检查的可选最小做法：在固定小邻域中，将物理坐标下的 `s_v=grad_v log f` 组成加权设计矩阵，用 SVD 查看三个方向的尺度与最弱方向，而不是只看粒子数。若进一步近似邻域内 `grad(Phi)` 恒定，用 `s_v·grad(Phi)=v·s_x` 做局部最小二乘诊断，须检查邻域尺度敏感性；变化过快的场会违反局部常量近似。低秩或小奇异值提示弱约束，满秩也不证明 DF 正确。禁止对噪声局部力估计再直接差分并称作密度真值。

这个局部线性思路有 CBE 直接求解工作的依据，但本文的有限样本 SVD 仅是诊断代理，不等价于其完整唯一性定理：[An et al., 2021](https://arxiv.org/abs/2106.05981)。DF 与势通过稳态 CBE 联系的基本方法见 [Green & Ting, 2020](https://arxiv.org/abs/2011.04673)。

增加密度平滑正则、改势网络输出为正密度参数化或引入其他物理先验，都属于新的模型/目标假设；放在上述诊断之后，用真值控制和动力学误差验证代价。当前不默认启动这些修改。
